**Installation Instructions:** This plugin depends on BepInEx 5.4, please download and install BepInEx first, URL: https://github.com/BepInEx/BepInEx/releases/
Once BepInEx is installed, launch the game once so that BepInEx can create the required files and folders
Find the *BepInEx* folder in the game installation directory, click on it to find the *plugins* folder, the specific directory should look like this: (Steam installation location is omitted here)...\common\Nuclear Option\BepInEx\plugins
Unzip the compressed file in the release to get the NuclearOptionChinese folder and put it in the *plugins* folder mentioned above
launch the game.

**Features:** this plugin translates the game into Chinese
press F11 to open the console, where you can toggle the translation, reload the translation file(translation.json), and refresh translation on screen ,as well as adjust the scanning interval of  the translation, longer for better performance, shorter for more consistent experience.

安装说明：该插件依赖于BepInEx 5.4，请先下载并安装BepInEx，网址：https://github.com/BepInEx/BepInEx/releases/
在BepInEx安装好后，启动一次游戏以便BepInEx创建所需的文件和文件夹
在游戏安装目录里找到BepInEx文件夹，点开找到plugins文件夹，具体目录应该长这样：（此处省略steam安装位置）...\common\Nuclear Option\BepInEx\plugins
把release中的压缩文件解压，得到NuclearOptionChinese文件夹，将其放入上述的plugins文件夹内
然后启动游戏即可

功能：该插件会将游戏大部分文本翻译成中文
按 F11 打开控制台，你可以切换翻译、重新加载翻译文件（translation.json），并在屏幕上刷新翻译文本，还可以调整翻译的扫描间隔，延长以提升性能，缩短以获得更稳定的体验。
目前支持的版本：v0.32  不过，理论上来讲只要BepInEx允许，无论是什么版本都能兼容
